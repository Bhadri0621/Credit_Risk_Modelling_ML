# Credit Risk Modelling using Machine Learning

## 🚀 Live Demo
https://bh-credit-risk-modelling.streamlit.app/

## 📌 Overview
This project is a Machine Learning-based Credit Risk Modelling system developed to assess the creditworthiness of a loan applicant.

The system takes borrower information, loan details, and credit-behaviour indicators as input and predicts the probability of loan default using a trained Logistic Regression model.

The predicted probability is then converted into a custom credit score ranging from 300 to 900 and classified into four risk categories: Poor, Average, Good, and Excellent.

The complete prediction system is integrated into an interactive Streamlit web application, allowing users to enter applicant details and receive the risk assessment in real time.
